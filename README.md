# Vinay Tiwari

I build at the intersection of AI, software, electronics, and the physical world. I like taking a rough idea through to a working system, especially when software has to interact with a real device.

## Built and documented

- **[Vouch](https://github.com/vinaytiwaribuilds/vouch)** — a settlement-verification prototype built for the Razorpay AI Buildathon. It compares Razorpay recon, bank, and merchant ledger evidence, and leaves ambiguous cases open for review. The repository includes architecture, a live demo, and reproducible evaluation on synthetic data. It is not a production finance tool.

## Currently building

- **Project Soundwave** — a capability-driven command layer for connected devices. I have been working on its backend, dashboard, device communication, telemetry, and permission checks. I will share the technical material after reviewing it for public release.
- **CombiFlash** — a low-cost automated liquid-handling prototype. The current focus is proving a fixed-rack dispensing mechanism before product development.

## Earlier hardware work

- **Refrigerant leakage detector** — an independent prototype that received second prize at a college Green Tech Hackathon.
- **IoT pavement monitoring** — an ESP32/Arduino sensing concept for collecting road-condition data and mapping it with GIS.

I work with Python, embedded devices, sensors, automation, and web interfaces. My interests are strongest where those parts come together in a physical system.
